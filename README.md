A comprehensive CRM and administrative dashboard for Learning Management Systems (LMS) built with **Django**, providing student management, course enrollment tracking, teacher assignment, and administrative analytics.

---

## 🌟 Key Features

- **📊 Administrative Dashboard**: High-level metrics for student counts, course enrollments, and active classes.
- **👨‍🎓 Student & Teacher CRM**: Manage student records, teacher profiles, and role assignments.
- **📚 Course Management**: Create and structure courses, modules, lessons, and schedules.
- **🎨 Custom Admin UI**: Custom dashboard templates styled with HTML5, CSS3, and JavaScript.

---

## ⚙️ Quick Start

```bash
git clone https://github.com/Juravoyev/AdminLMS.git
cd AdminLMS

python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt

python manage.py migrate
python manage.py runserver
```
Open `http://127.0.0.1:8000/`.
